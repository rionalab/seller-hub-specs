# Architecture Decision Records

Catat keputusan teknis yang berdampak, bukan semua perubahan kode. Gunakan NNNN-judul-kebab-case.md. Jangan mengubah catatan lama menjadi sejarah palsu; tandai superseded dan tautkan pengganti.
Salin template.md saat membuat ADR. Dokumen architecture memuat kondisi terkini; ADR menyimpan alasan dan tradeoff.

[ADR 0012](0012-agnostic-blueprint-scope.md) menetapkan cakupan blueprint terkini dan menggantikan penerapan universal detail audit/logging pada ADR 0004–0011. Catatan lama dipertahankan sebagai riwayat dan referensi adopsi.

[ADR 0013](0013-seller-hub-starter-alignment.md) mencatat penerapan pada Seller Hub. ADR 0001–0012 berasal dari blueprint; ADR dengan nomor sama di agent legacy adalah riwayat berbeda dan tidak boleh dipakai sebagai aturan aktif.
